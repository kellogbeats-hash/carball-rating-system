### What This System Does / Bu Sistem Ne Yapar?

- ✅ **468+ Players** ranked with detailed stats
- ✅ **Search** by nickname
- ✅ **Sortable columns** for all statistics
- ✅ **Tier system** from S-Tier to E-Tier
- ✅ **Role classification** (Goalkeeper, Striker, Playmaker)
- ✅ **Full transparency** - all formulas are public

## 🎯 Features / Özellikler

| Feature | Description |
|---------|-------------|
| 📊 **Player Rankings** | View all players sorted by rating |
| 🔍 **Search** | Find any player by nickname instantly |
| 📈 **Stats** | Goals, Assists, Saves, Win Rate, MVP and more |
| 🏷️ **Tiers** | Color-coded tiers from S (best) to E (new) |
| 🎭 **Roles** | Tactical role classification for each player |
